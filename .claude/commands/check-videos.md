# 증시 유튜브 새 영상 체크 및 요약

한국 증시 유튜브 채널에서 새 영상을 확인하고, 자막을 추출하여 요약한 뒤 Slack/Notion에 저장하는 파이프라인을 실행합니다.

## 실행 순서

### 1단계: 새 영상 감지

`python3 scripts/fetch-new-videos.py`를 실행하여 새 영상 목록을 확인합니다.
결과가 `"count": 0`이면 "새 영상 없음"을 출력하고 종료합니다.

### 2단계: 각 영상 처리

새 영상이 있으면, 각 영상에 대해 아래를 순서대로 수행합니다:

#### 2-1. 자막 추출
`mmk youtube transcript <url>` 명령어로 자막을 추출합니다.
자막 추출이 실패하면 해당 영상은 건너뜁니다 (에러 로그 출력).

#### 2-2. AI 요약 생성
추출된 자막을 아래 형식으로 요약합니다:

- **한줄 요약**: 영상 핵심을 1문장으로
- **핵심 포인트**: 3~5개 불릿 포인트
- **언급 종목**: 영상에서 언급된 주식 종목명 목록 (없으면 "없음")
- **시장 전망**: 전반적 시장 방향성 요약 (강세/약세/중립 + 근거 1줄)

#### 2-3. Slack 알림 전송
`scripts/config.json`에서 `slack.enabled`가 `true`이고 `slack.channel_id`가 설정되어 있으면,
Slack MCP 도구 `slack_send_message`를 사용하여 아래 포맷으로 알림을 전송합니다:

```
*[채널명] 콘텐츠시리즈*
제목: 영상 제목
게시일: YYYY-MM-DD

*요약*
한줄 요약 내용

*핵심 포인트*
- 포인트 1
- 포인트 2
- 포인트 3

*언급 종목*: 삼성전자, SK하이닉스, ...

*시장 전망*: 강세 - 근거 내용

영상 링크: URL
```

Slack이 비활성화 상태이면 이 단계를 건너뜁니다.

#### 2-4. Notion 데이터베이스 저장
`scripts/config.json`에서 `notion.enabled`가 `true`이고 `notion.database_id`가 설정되어 있으면,
Notion MCP 도구 `notion-create-pages`를 사용하여 데이터베이스에 저장합니다.

속성 매핑:
- 제목 (Title): 영상 제목
- 채널 (Select): 채널명
- 콘텐츠시리즈 (Select): 시리즈명
- 요약 (Rich Text): 한줄 요약 + 핵심 포인트
- 언급종목 (Multi Select): 종목명 배열
- 영상URL (Rich Text): 영상 URL
- 게시일 (Date): 영상 게시일
- 처리일 (Date): 오늘 날짜

Notion이 비활성화 상태이면 이 단계를 건너뜁니다.

### 3단계: 처리 완료 기록

처리 완료된 영상의 video_id를 `data/processed.json`의 `video_ids` 배열에 추가합니다.
`python3 -c` 또는 직접 파일을 수정하여 업데이트합니다.

### 4단계: 결과 보고

처리 결과를 간결하게 보고합니다:
- 확인한 채널 수
- 새로 발견한 영상 수
- 요약 완료한 영상 수
- Slack 전송 여부
- Notion 저장 여부
